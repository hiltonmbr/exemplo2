# Exercício

Uma loja de varejo quer criar um pequeno sistema para calcular o valor final de uma compra. O sistema deve considerar o valor da compra e a forma de pagamento.

O progama deve solicitar o valor da compra. Os meios de pagamento e política de desconto são:

- 1 — Pix - 10% de desconto
- 2 — Dinheiro - 8% de desconto
- 3 — Cartão de débito - 5% de desconto
- 4 — Cartão de crédito -  → sem desconto

No final, o programa deve exibir o valor original, o desconto aplicado e o valor final.
